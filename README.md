## 🚀 30 秒上手

```bash
# 1. 装好 skill(一次性)
ln -s $(pwd) ~/.claude/skills/youzi

# 2. 打开 Claude Code,输入:
/youzi 在线协作工具

# 3. 等 5-15 分钟,报告自动生成,浏览器自动打开
```

报告长这样:

```
┌─────────────────────────────────────┐
│ 🎯 [主题] · 竞争格局与机会图谱        │
├─────────────────────────────────────┤
│ 01 背景与目标                          │
│ 02 结论与建议(SWOT + Top 3 机会)        │
│ 03 产品定位分析                        │
│ 04 商业策略分析(6 维评分 + 定价)         │
│ 05 产品设计(117 项功能 · 厂商对比矩阵)  │
│ 06 产品数据分析                        │
│ 07 用户反馈分析                        │
│ 08 其他竞品资料库(15 家市场全景)        │
│ ★ 来源与参考资料(168 条带 URL 证据)    │
└─────────────────────────────────────┘
```

> 💡 默认装 13 个爬虫**并行工作**,覆盖率从 50% 提升到 99%。推荐至少装 firecrawl + crawl4ai,详细看 [📦 安装说明](安装说明.md)。

## 🤔 这是什么?

**一个 Claude Code 的竞品分析 skill**:输入一个市场主题,自动产出含**带 URL 出处的 213 条来源**、**117 项竞品功能**、**6 维度雷达对比**、**9 章完整结构**的精美 HTML 报告。

```
你输入:/youzi <主题>
        │
        ▼
🕷️  爬取 → 智能路由(按页面类型自动选引擎组合,定价页交叉验证)
        │
        ▼
🧠  分析 → 13 字段提取 + SWOT + 6 维评分 + 市场空白 + 颠覆机会
        │
        ▼
📊  输出 → 单文件 HTML 报告(主题感知 + 响应式 + 浮动 TOC + 全 [N] 引用)
```

## ✨ 核心能力

| | 能力 | 说明 |
|---|---|---|
| 🕷️ | **智能引擎路由** | 13 引擎按页面类型智能组合 · 定价交叉验证 · 引擎表现自学习 |
| 🧠 | **13 字段结构化** | strengths/weaknesses/tech_signals 等 |
| 📑 | **9 章节完整** | 背景 / 结论 / 定位 / 商业 / 设计 / 数据 / 反馈 / §8 / Sources |
| 🔗 | **全板块可追溯** | 177 个 `[N]` 引用角标 · 213 条带 URL 来源 |
| 📊 | **117 项功能全集** | 每家竞品 18-22 个功能 · 39 类别 |
| 🎯 | **SWOT 全图** | 6 深度 + 15 §8 其他竞品 = 21 张 SWOT 卡 |
| 📈 | **6 维评分对比** | 评分矩阵 + 奖牌 + 综合分 + 领先/中坚/跟随分级 |
| 🌗 | **主题感知** | 浅色 / 深色 / 跟随系统 |
| 📱 | **响应式** | 桌面 / 平板 / 手机 |
| 🛠️ | **单第三方包** | 渲染仅需 `jinja2`(已加入安装说明) |
