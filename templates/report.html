📐 分析方法与数据流

  1. 发现竞品：WebSearch 6+ 角度 + G2/Crunchbase/Reddit 评分 + 主流媒体编辑视角
  2. 深度爬取：fetch.py 统一取证 — 5 引擎白名单 (playwright/trafilatura/newspaper3k/jina/firecrawl) 按页面类型智能路由,抓取官网 + pricing + features + docs + 关于/客户页;定价页 JS 组 + 静态对照双通道,每引擎原文独立留存供交叉验证
  3. 结构化抽取：对每家竞品抽取 13 字段 (tagline/founded/stage/scores/strengths/weaknesses/differentiators/tech_signals/pricing/features...)
  4. 同义合并：通过 feature_aliases 配置将同义功能 (如「团队收件箱」/「团队共享收件箱」) 合并到 canonical,保留各厂商实际叫法
  5. 证据三元组提取 + 6 维评分 + 市场空白/颠覆机会推导 + 来源追溯
  6. 输出 HTML 报告：每个结论带 N 出处,可点击跳转文末原始来源

📖 阅读建议

结论先行：先看 §2 结论与建议 → §3 产品定位 → §5.2 功能对比矩阵
