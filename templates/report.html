  2. 深度爬取：11 个爬虫 (firecrawl/crawl4ai/trafilatura/newspaper3k/readability/markdownify/playwright/scrapy/jina/html2text/requests-html) 并行抓取官网 + pricing + features + reviews + docs + G2 评测,智能合并去重
  3. 结构化抽取：对每家竞品抽取 13 字段 (tagline/founded/stage/scores/strengths/weaknesses/differentiators/tech_signals/pricing/features...)

  6. 输出 HTML 报告：每个结论带 N 出处,可点击跳转文末原始来源
